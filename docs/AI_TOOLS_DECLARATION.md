# Δήλωση χρήσης εργαλείων AI στην ανάπτυξη
> Συμπληρώστε ό,τι πρόσθετο χρησιμοποιεί κάθε μέλος της ομάδας. Η δήλωση πρέπει να είναι πλήρης.

| Εργαλείο | Για τι χρησιμοποιήθηκε | Ποιος το χρησιμοποίησε |
|---|---|---|
| Claude Code (Anthropic) | Αρχιτεκτονική, κώδικας backend (Python), τεστ, εργαλεία build, έγγραφα, προσχέδια παρουσίασης | Αναστάσης Αναστασίου, Σοφία Δημητρίου, Ορέστης Κακαβάς, Χρήστος Γεωργίου |
| Lovable | Παραγωγή και επεξεργασία του κώδικα του front end (React), υπό καθοδήγηση προτροπών (prompts) που γράφτηκαν από την ομάδα/Claude. Το τελικό build ελέγχεται (χωρίς εξωτερικές κλήσεις) | Αναστάσης Αναστασίου, Σοφία Δημητρίου, Ορέστης Κακαβάς, Χρήστος Γεωργίου |
| Gemini (Google) | Αρχικό πλάνο και ιδέες | Αναστάσης Αναστασίου, Σοφία Δημητρίου, Ορέστης Κακαβάς, Χρήστος Γεωργίου |
| Δεύτερη υλοποίηση ομάδας (με τα εργαλεία AI που δηλώνονται παραπάνω) | Εναλλακτικός αλγόριθμος· υιοθετήθηκαν οι ιδέες PU-learning ανά profile, αναλογική συγχώνευση, ομαλή γεωγραφία και απόσβεση θορυβώδους δευτερεύοντα ΚΑΔ, επανυλοποιημένες στον κώδικα του έργου και δοκιμασμένες | Αναστάσης Αναστασίου, Σοφία Δημητρίου, Ορέστης Κακαβάς, Χρήστος Γεωργίου |

**Τι ΔΕΝ χρησιμοποιείται:** καμία εξωτερική υπηρεσία AI/API κατά την εκτέλεση της εφαρμογής. Το μόνο μοντέλο που τρέχει στην εφαρμογή
είναι το EuroLLM-9B-Instruct (Apache-2.0) μέσω Ollama τοπικά, και embeddings TF-IDF χαρακτήρων + SVD (scikit-learn, χωρίς νευρωνικό μοντέλο) τοπικά.
Ο κώδικας που παρήχθη με τη βοήθεια AI ελέγχθηκε και δοκιμάστηκε από την ομάδα (αυτόματα τεστ + δοκιμές στους υπολογιστές των μελών).
