# Τοπική ανάλυση πελατών — front end

Η εφαρμογή χρησιμοποιεί αποκλειστικά το τοπικό API για δεδομένα και ανάλυση.

## Στατική έκδοση

```sh
npm install
npm run build
```

Το `dist/index.html` και το υπόλοιπο `dist/` σερβίρονται από οποιονδήποτε στατικό HTTP server, χωρίς server εφαρμογής. Το `npm run preview` σερβίρει τη στατική έκδοση. Για τις σελίδες `/map` και `/whatif`, ο στατικός server πρέπει να επιστρέφει το `index.html` όταν δεν υπάρχει αντίστοιχο αρχείο (SPA fallback). Η ενεργή ανάλυση διατηρείται στη μνήμη κατά την πλοήγηση· μετά από ανανέωση απαιτείται νέα ανάλυση.


## Διεύθυνση API

Προεπιλογή: `http://localhost:8000`. Για άλλη διεύθυνση, ορίστε `VITE_API_BASE` πριν από την παραγωγή της έκδοσης, π.χ. σε `.env.local`:

```text
VITE_API_BASE=http://localhost:8000
```

Ο server πρέπει να επιτρέπει CORS από τη διεύθυνση της εφαρμογής. Το `localhost` αναφέρεται στον υπολογιστή όπου εκτελείται ο browser. Σε φιλοξενία HTTPS, ο browser μπορεί να ζητήσει άδεια πρόσβασης στο τοπικό δίκτυο ή να περιορίσει μη ασφαλείς συνδέσεις· η τοπική στατική σερβίριση HTTP αποφεύγει αυτή τη διαφορά περιβάλλοντος.

Δεν υπάρχουν mock δεδομένα, τεχνητές καθυστερήσεις ή παραγωγή AI μέσα στην εφαρμογή.

## Παρουσίαση και εξερεύνηση

- Ο διακόπτης «Λειτουργία παρουσίασης» μεγαλώνει τα κείμενα και εμφανίζει τέσσερα βήματα επίδειξης.
- Ο «Χάρτης» σχεδιάζεται με SVG χωρίς πλακίδια ή εξωτερικές βιβλιοθήκες, από `/api/geo/density` και `/api/geo/municipalities`.
- Το «Τι θα γινόταν αν» στέλνει τα τέσσερα βάρη στο `/api/jobs/{job}/whatif`, με ακύρωση προηγούμενου αιτήματος και καθυστέρηση 600 ms μετά την αλλαγή. Η μέτρηση ακρίβειας χρησιμοποιεί το ίδιο endpoint με `evaluate=true`.
- Τα νέα endpoints απαιτούν τον τοπικό server v18b που αναφέρεται στις οδηγίες.
